# Calculator

## About the Project

A responsive calculator application built using HTML, CSS, and JavaScript. It supports basic arithmetic operations, percentages, decimal calculations, and keyboard input with an interactive user interface.

## Features

- Addition, subtraction, multiplication, and division.
- Percentage calculations.
- Decimal number support.
- Clear all input using AC.
- Delete the last entered character using DEL.
- Keyboard support for numbers and operators.
- Error handling for invalid expressions and division by zero.
- Responsive design for mobile, tablet, and desktop screens.
- Interactive buttons with hover and click effects.
- Arithmetic expression evaluation without using `eval()`.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use the calculator buttons or keyboard to perform calculations.

## Keyboard Controls

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `+`, `-`, `*`, `/` | Arithmetic operations |
| `%` | Percentage |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete the last character |
| `Escape` or `Delete` | Clear the display |
